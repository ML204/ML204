<Section label="What is it?">

A **pandas Series** is a one-dimensional, labeled array. A **pandas DataFrame** is a two-dimensional collection of labeled columns. pandas is built on top of NumPy, so both structures store data in NumPy-backed arrays while adding useful labels and tabular operations.

```python
import pandas as pd

scores = pd.Series([82, 91, 78], name='score')
print(scores)

students = pd.DataFrame({
    'name': ['Asha', 'Ben', 'Chen'],
    'score': [82, 91, 78],
    'passed': [True, True, True],
})
print(students)
```

In a Series, one index belongs to all values. In a DataFrame, the same row index applies across multiple columns.

</Section>

<Section label="Why we need it">

Machine learning datasets are usually tables: each row is a sample, and each column is a feature or target. DataFrames make loading, inspecting, cleaning, and transforming those tables possible with a few readable expressions.

- **Series** represent a single feature or target column.
- **DataFrames** represent complete datasets.
- **Indexes** identify rows and support fast, label-aware operations.
- **Dtypes** affect memory use, missing-value behavior, and which operations are valid.

</Section>

### Creating and inspecting a Series

```python
scores = pd.Series(
    [82, 91, 78, 88],
    index=['Asha', 'Ben', 'Chen', 'Diego'],
    name='score',
    dtype='int64',
)

print(scores.index)   # Index(['Asha', 'Ben', 'Chen', 'Diego'], dtype='object')
print(scores.to_numpy())  # NumPy values used internally
print(scores.dtype)   # int64
print(scores.head(2))
```

The index labels are separate from the array values. Labels make outputs easier to understand, but they are not the same as `.iloc` positions.

<Analogy>
  A Series is like a labeled column in a spreadsheet. The values are in the column, while the index labels identify each row. A DataFrame is several of these labeled columns sharing the same row index.
</Analogy>

### Creating and inspecting a DataFrame

```python
students = pd.DataFrame({
    'name': ['Asha', 'Ben', 'Chen'],
    'score': [82, 91, 78],
    'passed': [True, True, True],
})

print(students.head())       # First five rows
print(students.tail(2))      # Last two rows
print(students.info())       # Columns, dtypes, and memory usage
print(students.describe())   # Numeric summary statistics
print(students.shape)        # (rows, columns)
print(students.dtypes)       # dtype of every column
```

Use `head()` and `tail()` for quick samples, `shape` for dimensions, `dtypes` for column types, `info()` for an overview, and `describe()` for numerical summary statistics.

### Memory-efficient categories

A text column with only a few repeated values may waste memory if pandas stores every string separately. The `category` dtype stores each unique value once and uses integer codes for the rows.

```python
students['passed'] = students['passed'].astype('category')
print(students['passed'].dtype)
print(students['passed'].cat.categories)

students = pd.read_csv(
    'students.csv',
    dtype={'grade': 'category', 'student_id': 'string'},
)
```

<Callout kind="tip">
  Convert categorical columns such as grade, country, payment status, or department to `category` when the number of unique values is much smaller than the number of rows.
</Callout>

<Callout kind="warning">
  Do not convert every text column to `category`. Free-form text such as reviews or comments may contain nearly one unique string per row, which provides little memory benefit.
</Callout>
