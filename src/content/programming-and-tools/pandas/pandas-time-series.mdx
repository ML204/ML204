<Section label="What is it?">

A pandas time series stores observations associated with dates or timestamps. A `DatetimeIndex` allows sorting, slicing, resampling, and aggregation by time.

```python
prices = pd.read_csv('prices.csv', parse_dates=['date'])
prices = prices.set_index('date').sort_index()
```

</Section>

<Section label="Why we need it">

Forecasting and monitoring depend on ordered time. Correct parsing enables monthly summaries, rolling trends, timezone-aware events, and lag features that use previous observations.

</Section>

<Divider />

<Section label="Explained in detail">

### Parsing and datetime accessors

```python
sales = pd.DataFrame({
    'time': ['2026-01-01 09:30', '2026-01-02 10:15'],
    'amount': [20, 35],
})
sales['time'] = pd.to_datetime(sales['time'], errors='coerce')

print(sales['time'].dt.year)
print(sales['time'].dt.month)
print(sales['time'].dt.day_name())
print(sales['time'].dt.hour)
```

`.dt` exposes datetime properties and methods from a datetime Series.

### DatetimeIndex and resampling

```python
daily = pd.DataFrame({
    'date': pd.to_datetime(['2026-01-01','2026-01-02','2026-01-31','2026-02-01']),
    'value': [10,20,30,40],
}).set_index('date')

monthly = daily.resample('ME').mean()
print(monthly)
```

`resample('ME')` groups observations into calendar month ends.

### Rolling windows and lag features

```python
daily['rolling_7'] = daily['value'].rolling(window=7, min_periods=1).mean()
daily['lag_1'] = daily['value'].shift(1)
daily['lag_7'] = daily['value'].shift(7)
```

A rolling mean summarizes observations in a window. `shift(1)` moves values forward by one observation.

<Callout kind="warning">
  Create lag features only after sorting timestamps. A lag is future-safe only when it references strictly earlier observations.
</Callout>

### Time zones

```python
aware = sales['time'].dt.tz_localize('Asia/Dhaka')
utc = aware.dt.tz_convert('UTC')
```

Localize attaches a zone to naive timestamps. Convert changes an aware timestamp to another zone.

<Analogy>
  A DatetimeIndex is a calendar ruler. Resampling gathers observations between ruler marks, rolling windows slide across the ruler, and shift copies earlier marks to the current position.
</Analogy>

</Section>
