<Section label="What is it?">

**Data ingestion** reads external files into a pandas DataFrame. The common entry points are `read_csv`, `read_excel`, and `read_json`. Each reader turns text or structured bytes into labeled rows and columns.

```python
import pandas as pd

customers = pd.read_csv('customers.csv')
sales = pd.read_excel('sales.xlsx', sheet_name='2026')
events = pd.read_json('events.json')
```

</Section>

<Section label="Why we need it">

The source format, encoding, and schema can change before machine learning code starts. Reliable ingestion prevents silent type conversion, broken characters, incorrect dates, and memory exhaustion.

</Section>

<Divider />

<Section label="Explained in detail">

### CSV files

```python
orders = pd.read_csv(
    'orders.csv',
    encoding='utf-8',
    na_values=['NA', 'N/A', 'unknown'],
    parse_dates=['order_date'],
    usecols=['order_id', 'customer', 'order_date', 'amount'],
)

print(orders.dtypes)
```

- `encoding` determines how bytes become text.
- `na_values` turns selected strings into missing values.
- `parse_dates` converts date columns during ingestion.
- `usecols` avoids loading unnecessary columns.

<Callout kind="warning">
  Never assume dates are parsed correctly. Inspect `DataFrame.dtypes` and convert with `pd.to_datetime(..., errors='coerce')` when source values are inconsistent.
</Callout>

### Excel and JSON

```python
inventory = pd.read_excel(
    'inventory.xlsx',
    sheet_name='Warehouse',
    usecols='A:D',
    na_values=['-'],
)

logs = pd.read_json('logs.json', lines=True)
```

Use `sheet_name` for Excel and `lines=True` for newline-delimited JSON.

### Chunking large files

```python
chunk_reader = pd.read_csv('large_events.csv', chunksize=100_000)
filtered_chunks = []

for chunk in chunk_reader:
    filtered_chunks.append(chunk.loc[chunk['active'] == True])

active_events = pd.concat(filtered_chunks, ignore_index=True)
```

`chunksize` yields a DataFrame iterator instead of loading the complete file. Process or filter one chunk at a time.

### Exporting data

```python
orders.to_csv('clean_orders.csv', index=False)
orders.to_json('clean_orders.json', orient='records', lines=True)
orders.to_excel('clean_orders.xlsx', index=False, sheet_name='Orders')
orders.to_parquet('clean_orders.parquet', index=False)
```

<Analogy>
  Data ingestion is like moving boxes from different warehouses. CSV is a flat text manifest, Excel is a labeled workbook, JSON is a nested package, and Parquet is compact analytical storage.
</Analogy>
