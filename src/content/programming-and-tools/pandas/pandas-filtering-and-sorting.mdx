<Section label="What is it?">

Selecting chooses columns or rows. Filtering keeps rows that satisfy conditions. Sorting reorders rows according to column values or index labels.

```python
rows = df.loc[df['score'] >= 80, ['name', 'score']]
rows = rows.sort_values('score', ascending=False)
```

</Section>

<Section label="Why we need it">

Cleaning and model preparation repeatedly require subsets: remove invalid rows, isolate a class, find missing values, rank observations, or test a model on a named slice.

</Section>

<Divider />

<Section label="Explained in detail">

### `.loc` versus `.iloc`

`.loc` uses labels. `.iloc` uses integer positions.

```python
frame = df.set_index('name')
print(frame.loc['Asha', 'score'])
print(frame.iloc[0, 1])
print(frame.loc['Asha':'Chen', ['score']])
```

<Callout kind="warning">
  `.loc` slicing includes the end label. `.iloc` slicing excludes the end position.
</Callout>

### Boolean masks

```python
mask = (df['score'] >= 80) & (df['passed'] == True)
selected = df.loc[mask, ['name', 'score']]

other = df.loc[
    df['country'].isin(['BD', 'US']) & ~df['score'].isna(),
    ['name', 'country', 'score'],
]
```

Use parentheses around conditions and `&`, `|`, `~` instead of Python `and`, `or`, `not` for elementwise pandas operations.

### String accessors and sorting

```python
emails = df.loc[df['email'].str.contains(r'@example\.com$', na=False)]
ranked = df.sort_values(['country', 'score'], ascending=[True, False])
ranked_by_name = df.sort_index()
```

<Analogy>
  A Boolean mask is a check mark for every row. Combining masks with `&` and `|` is like stacking filters on a spreadsheet.
</Analogy>

### Reading each selection expression

A useful selection has the form:

```python
rows = df.loc[row_mask, [column_names]]
```

The first position describes which rows survive. The second position describes which columns remain:

```python
high_scores = df.loc[
    (df['score'] >= 80) & (df['country'].isin(['BD', 'US'])),
    ['name', 'score', 'country'],
]
```

| Expression | Meaning |
| :--- | :--- |
| `df['score'] >= 80` | Compare every score and create a Boolean Series. |
| `&` | Keep rows true in both masks. |
| `|` | Keep rows true in either mask. |
| `~` | Reverse true and false values. |
| `.isin(values)` | Test whether each value belongs to a list. |
| `.isna()` | Test whether each value is missing. |

### Avoiding chained assignment surprises

Selecting a DataFrame and changing it in two separate steps can change a temporary copy instead of the original:

```python
# Risky: chained assignment
# df[df['score'] < 0]['score'] = 0

# Safer: build a mask, then assign with loc
invalid_score = df['score'] < 0
df.loc[invalid_score, 'score'] = 0
```

`.loc` keeps selection and assignment in one operation, making the intended target explicit.

<Callout kind="warning">
  Sorting and filtering return a new view or copy depending on the operation. Do not assume the original DataFrame changed. Reassign it or use `.loc` assignment when the change should persist.
</Callout>

When building a ranked report, sort only after selecting the needed rows and columns:

```python
report = (
    df.loc[df['score'].notna(), ['name', 'score', 'country']]
      .sort_values(['country', 'score'], ascending=[True, False])
)
```
