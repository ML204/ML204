<Section label="What is it?">

**groupby** splits rows by key values, applies a function to each group, and combines the results.

```python
summary = sales.groupby('region')['amount'].agg(['sum', 'mean', 'count'])
```

</Section>

<Section label="Why we need it">

Summaries often require per-group calculations: average loss by product category, accuracy by customer segment, or feature averages for each label.

</Section>

<Divider />

<Section label="Explained in detail">

### Split, apply, combine

```python
sales = pd.DataFrame({
    'region': ['East', 'East', 'West', 'West'],
    'amount': [20, 30, 15, 45],
})

print(sales.groupby('region')['amount'].sum())
print(sales.groupby('region')['amount'].agg(['sum', 'mean', 'count']))
```

Built-in aggregations include `sum`, `mean`, `std`, `count`, `median`, `min`, and `max`.

### Named aggregations

```python
summary = sales.groupby('region').agg(
    revenue=('amount', 'sum'),
    average_order=('amount', 'mean'),
    order_count=('amount', 'count'),
)
```

Named aggregation gives each output column a clear name and allows several calculations in one operation.

### Transforming within groups

`transform` returns one output value per original row, aligned to the original index.

```python
sales['region_mean'] = sales.groupby('region')['amount'].transform('mean')
sales['amount_minus_region_mean'] = (
    sales['amount'] - sales['region_mean']
)
```

Use `transform` for group-standardization or group-relative features. Use `agg` when one result per group is desired.

### Pivot tables

```python
sales['category'] = ['A', 'B', 'A', 'B']
pivot = sales.pivot_table(
    values='amount',
    index='region',
    columns='category',
    aggfunc='sum',
    fill_value=0,
)
```

<Analogy>
  groupby is a team organizer. It sorts rows into teams, gives each team a calculation, and reports one result per team. transform gives every player a team statistic while retaining one result per player.
</Analogy>

<Callout kind="warning">
  `count` counts non-missing values, while `size` counts every row in a group. Choose correctly when missing values are present.
</Callout>
