<Section label="What is it?">

Python provides four fundamental built-in collection data structures:
- **List (`[]`)**: An ordered, mutable sequence of heterogeneous elements.
- **Tuple (`()`)**: An ordered, immutable sequence used for fixed records and constant shapes.
- **Dictionary (`{}`)**: An associative key-value mapping backed by a high-speed hash table with $O(1)$ average lookup time.
- **Set (`set()`, `{}`)**: An unordered collection of unique, hashable items supporting set-theoretic operations (union, intersection, difference).

</Section>

<Section label="Why we need it">

In machine learning and data engineering:
- **Lists** store dynamic metrics, training histories, and batches of file paths: `losses.append(batch_loss)`.
- **Tuples** represent fixed structural dimensions and tensor shapes: `shape = (batch_size, 3, 224, 224)`.
- **Dictionaries** store hyperparameter configurations, metrics dictionaries, and JSON model weights: `config = {"lr": 1e-3, "epochs": 50}`.
- **Sets** deduplicate vocabulary tokens, track visited states in reinforcement learning, and compute set overlaps: `vocab = set(tokens)`.

Understanding their time complexities and memory trade-offs prevents computational bottlenecks when processing large datasets.

</Section>

<Section label="Explained in detail">

### 1. Lists: Mutable Sequences

Lists are dynamic arrays. Appending to the end is $O(1)$ amortized, while inserting or deleting from the middle is $O(n)$ because remaining elements must shift in memory:

```python
# List creation and operations
features = ["area", "bedrooms", "age"]
features.append("bathrooms")        # Add to end: O(1)
features.insert(0, "zip_code")      # Insert at front: O(n)
print("Slice [1:3]:", features[1:3]) # ['area', 'bedrooms']
```

### 2. Tuples: Immutable Records

Once created, tuple elements cannot be modified, added, or removed. Because they are immutable and hashable (if their contents are hashable), tuples can serve as dictionary keys:

```python
# Fixed image coordinates and tensor shapes
img_dims = (1920, 1080)
spatial_weights = {(0, 1): 0.45, (1, 0): 0.55}

# Unpacking tuples cleanly
width, height = img_dims
print(f"Width: {width}, Height: {height}")
```

<Analogy>
  Think of a list as a loose-leaf binder where you can add, remove, and reorder pages anytime. A tuple is a printed paperback book: once bound, the pages cannot be modified or re-indexed.
</Analogy>

### 3. Dictionaries: Fast $O(1)$ Key-Value Hash Maps

Dictionaries map unique keys to values using hash tables. They preserve insertion order (in Python 3.7+):

```python
metrics = {
    "train_loss": 0.24,
    "val_loss": 0.31,
    "accuracy": 0.945,
}

# Safe lookup with default fallback
recall = metrics.get("recall", 0.0)

# Iterating over key-value pairs
for metric, score in metrics.items():
    print(f"{metric}: {score:.3f}")
```

### 4. Sets: Unordered Unique Collections

Sets enforce uniqueness and provide $O(1)$ average membership testing (`x in my_set`):

```python
corpus_a = {"neural", "network", "gradient", "descent"}
corpus_b = {"gradient", "boosting", "tree", "forest"}

# Set theoretic operations
common_words = corpus_a & corpus_b        # Intersection: {'gradient'}
all_words = corpus_a | corpus_b           # Union
unique_to_a = corpus_a - corpus_b         # Difference
```

<Callout kind="warning">
  **Dictionary & Set Keys Must Be Hashable:** You can use strings, numbers, and tuples as dictionary keys or set members. You **cannot** use mutable objects like lists or other dictionaries (`unhashable type: 'list'`).
</Callout>
