<Section label="What is it?">

**Diagnostic Visualization** is the systematic application of statistical charts to audit raw features during Exploratory Data Analysis (EDA). Before passing features into linear models, support vector machines, or neural networks, machine learning engineers must diagnose four core data characteristics:

1. **Univariate Distribution & Skewness**: Are features Gaussian, bimodal, heavy-tailed, or heavily zero-inflated? (Diagnosed with **Histograms** and **KDE plots**).
2. **Bivariate Interactions & Non-Linearity**: Are pairs of features linearly related, clustered, or constrained by non-linear relationships? (Diagnosed with **Scatter plots** and **Joint plots**).
3. **Outliers & Dispersion**: Are there anomalous sensor glitches or fat-tailed distribution spikes? (Diagnosed with **Box plots** and **Violin plots**).
4. **Multicollinearity**: Are features redundantly duplicating information, risking unstable model coefficients? (Diagnosed with **Correlation Heatmaps**).

```
Raw Tabular Data
  ├── 1D Shape & Normality  ──> Histograms & KDE (sns.histplot, sns.kdeplot)
  ├── 2D Bivariate Form     ──> Scatter & Joint Plots (sns.scatterplot, sns.jointplot)
  ├── Anomalies & Spread    ──> Box & Violin Plots (sns.boxplot, sns.violinplot)
  └── Multi-Feature Coupling──> Masked Heatmaps (sns.heatmap)
```

</Section>

<Section label="Why we need it">

In machine learning pipelines:
- **Preventing Gradient Instability**: Linear regression, logistic regression, and neural networks perform poorly on heavily right-skewed features (e.g. income or transaction amounts spanning 6 orders of magnitude). Identifying positive skew via histograms prompts log or Box-Cox transformations ($\log(1 + x)$).
- **Automating Outlier Treatment**: Distance-based algorithms (k-Means, k-NN, SVMs) and MSE-loss regressors are heavily distorted by extreme outliers. Tukey's IQR rule on box plots gives a principled, non-parametric boundary to detect or clip anomalies.
- **Taming Multicollinearity**: When two input features have a Pearson correlation $r > 0.95$, matrix inversion $(X^T X)^{-1}$ in Ordinary Least Squares becomes ill-conditioned, blowing up weight variance. A correlation heatmap immediately exposes collinear pairs for removal or PCA reduction.

</Section>

### 1. Univariate Distribution: Histograms and Kernel Density Estimation (KDE)

A **Histogram** divides continuous data into discrete bins along the X-axis and counts the number of observations falling into each bin. **Kernel Density Estimation (KDE)** fits smooth Gaussian kernels over every point to produce a continuous probability density estimate:

```python
import numpy as np
import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt

fig, axes = plt.subplots(1, 2, figsize=(12, 4.5))

# Generating a heavily right-skewed feature (e.g., e-commerce transaction amounts):
raw_transactions = np.random.exponential(scale=50, size=2000)

# Left Subplot: Raw Skewed Distribution
sns.histplot(
    raw_transactions,
    kde=True,
    bins=40,
    color="#ef4444",
    stat="density",
    ax=axes[0]
)
axes[0].set_title("Raw Feature: Severe Positive (Right) Skew", fontweight="bold")
axes[0].set_xlabel("Transaction Amount ($)")

# Right Subplot: Log-Transformed Normalization: y = log1p(x)
log_transactions = np.log1p(raw_transactions)
sns.histplot(
    log_transactions,
    kde=True,
    bins=30,
    color="#059669",
    stat="density",
    ax=axes[1]
)
axes[1].set_title("Log-Transformed: Approaching Normal Distribution", fontweight="bold")
axes[1].set_xlabel("log(1 + Transaction Amount)")

plt.tight_layout()
plt.show()
```

<Analogy>
  Think of a **Histogram** like coins sorted into physical wooden slots: you only see discrete stack heights. A **Kernel Density Estimate (KDE)** is like pouring molten wax over the coin stacks: the wax smooths out the jagged stairsteps into a continuous fluid landscape, revealing the underlying probability contour.
</Analogy>

### 2. Outlier Detection: Box Plots and Tukey's 1.5 &times; IQR Rule

A **Box Plot** provides a standardized 5-number non-parametric summary of a continuous distribution:

```
           Q1 - 1.5*IQR                Q1          Median (Q2)       Q3                Q3 + 1.5*IQR
            Lower Whisker              |-----------|-----------|     Upper Whisker     Outliers
  ───|            |====================|           |           |===================|     o    o
                  |                    |-----------|-----------|                   |
                  |<─────────────────────── IQR ──────────────────────────────────>|
```

- **Median ($Q_2$ / 50th percentile)**: The bold center line dividing the dataset in half.
- **First Quartile ($Q_1$ / 25th percentile)**: The bottom/left edge of the box.
- **Third Quartile ($Q_3$ / 75th percentile)**: The top/right edge of the box.
- **Interquartile Range ($\text{IQR} = Q_3 - Q_1$)**: The middle 50% spread of observations.
- **Whiskers**: Extend to the furthest data points within $[Q_1 - 1.5 \times \text{IQR}, Q_3 + 1.5 \times \text{IQR}]$.
- **Outliers**: Any sample falling beyond the whisker boundaries is plotted as an individual flier dot.

```python
fig, axes = plt.subplots(1, 2, figsize=(12, 5))

# Boxplot comparing distributions across categorical groups:
sns.boxplot(
    data=df_telco,
    x="churn",
    y="monthly_charges",
    palette=["#3b82f6", "#ef4444"],
    ax=axes[0]
)
axes[0].set_title("Box Plot: Median & Quartile Outlier Detection")

# Violin Plot: Combines boxplot quartiles with full KDE density shapes:
sns.violinplot(
    data=df_telco,
    x="churn",
    y="monthly_charges",
    palette=["#3b82f6", "#ef4444"],
    inner="quartile",
    ax=axes[1]
)
axes[1].set_title("Violin Plot: Unveiling Bimodal Density Contours")
plt.show()
```

<Callout kind="tip">
  **Why Violin Plots Matter**: A standard boxplot cannot distinguish between a single bell curve and a bimodal distribution (a distribution with two distinct peaks). A **Violin Plot** displays the full probability density contour on both sides of the internal boxplot, exposing hidden subgroup clusters!
</Callout>

### 3. Bivariate Relationships: Scatter and Joint Plots

To examine non-linear interactions, heteroscedasticity, or dense clusters:

```python
# A JointPlot renders the central bivariate relationship alongside marginal 1D distributions:
joint = sns.jointplot(
    data=df_churn,
    x="account_age_months",
    y="total_charges",
    hue="churn",
    kind="scatter",
    alpha=0.6,
    palette="coolwarm",
    height=7
)
joint.plot_joint(sns.kdeplot, color="r", zorder=0, levels=6, alpha=0.5)
joint.fig.suptitle("Joint Distribution: Bivariate Scatter with Marginal KDEs", y=1.02)
```

### 4. Correlation Heatmaps: Auditing Multicollinearity

The **Pearson Correlation Coefficient** ($r \in [-1, 1]$) measures the strength and direction of linear associations between continuous variables:

$$\rho_{X, Y} = \frac{\text{Cov}(X, Y)}{\sigma_X \sigma_Y}$$

In feature sets with 20+ columns, inspecting raw tabular numbers is overwhelming. A masked, annotated heatmap provides an instantaneous visual diagnostic:

```python
# 1. Compute Pearson correlation matrix
corr_matrix = df_features.corr(method="pearson")

# 2. Generate a boolean mask for the redundant upper triangle:
# Because corr(A, B) == corr(B, A), the upper triangle contains identical information
mask = np.triu(np.ones_like(corr_matrix, dtype=bool))

# 3. Render masked heatmap with diverging palette centered strictly at zero
fig, ax = plt.subplots(figsize=(10, 8))
sns.heatmap(
    corr_matrix,
    mask=mask,
    annot=True,
    fmt=".2f",
    cmap="coolwarm",
    vmin=-1.0,
    vmax=1.0,
    center=0.0,
    square=True,
    linewidths=0.5,
    cbar_kws={"shrink": 0.8, "label": "Pearson Correlation r"},
    ax=ax
)

ax.set_title("Masked Correlation Matrix: Diagnosing Multicollinearity", fontsize=14, fontweight="bold", pad=12)
plt.show()
```

<Callout kind="warning">
  **Pearson vs. Spearman Correlation**: Pearson correlation only measures *linear* relationships. If two features have a monotonic but non-linear relationship (e.g. $y = e^x$), Pearson correlation will underestimate their dependency ($r \approx 0.82$), while **Spearman Rank Correlation** (`df.corr(method='spearman')`) will correctly detect a perfect monotonic relationship ($r_s = 1.0$).
</Callout>
