<Section label="What is it?">

A **loss function** is a formula that measures how wrong a model's predictions are. It takes the model's predictions and the true answers, and returns a single number — the loss. A smaller loss means better predictions.

</Section>

<Section label="Why we need it">

A model makes predictions. Those predictions are rarely perfect. We need a way to measure *how far off* they are — a single number that summarizes the total error across all examples.

That number is the loss. It is the thing we minimize during training. Without a loss function, the model has no feedback and cannot improve.

The choice of loss function matters. Different loss functions penalize errors differently, and the right choice depends on your problem.

</Section>

<Divider />

<Section label="Explained in detail">

Suppose you are predicting house prices. You have 4 houses. The model predicts prices, and you know the actual prices.

<Analogy>
  The loss function is like a report card. It does not grade each house separately — it gives you one overall score for how well you did across all of them.
</Analogy>

**Two common loss functions for regression:**

**Mean Squared Error (MSE)** — take each error (prediction − true), square it, then average all the squares:

$$
\text{MSE} = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2
$$

Squaring does two things: it makes all errors positive (so they do not cancel out), and it **punishes large errors heavily** — a error of 10 counts 100 times more than an error of 1.

**Mean Absolute Error (MAE)** — take the absolute value of each error (always positive), then average:

$$
\text{MAE} = \frac{1}{n} \sum_{i=1}^{n} |y_i - \hat{y}_i|
$$

MAE treats all errors proportionally. An error of 10 is exactly 10 times worse than an error of 1.

**Which to use?**
- Use **MSE** when large errors are especially bad (e.g. medical predictions).
- Use **MAE** when you want to be robust to outliers — one very wrong prediction does not dominate.

</Section>

<Section label="Notes & Formula">

<Formula label="Mean Squared Error (MSE)">
  $L_\text{MSE} = \dfrac{1}{n} \displaystyle\sum_{i=1}^{n} (y_i - \hat{y}_i)^2$
</Formula>

<Formula label="Mean Absolute Error (MAE)">
  $L_\text{MAE} = \dfrac{1}{n} \displaystyle\sum_{i=1}^{n} |y_i - \hat{y}_i|$
</Formula>

<Callout kind="tip">
  MSE is the most commonly used loss for regression because it is smooth and easy to differentiate — which makes gradient descent work cleanly.
</Callout>

<Callout kind="warning">
  **Common mistake:** confusing loss (training error) with accuracy (a separate evaluation metric). Loss is computed during training to guide updates. Accuracy is computed separately to evaluate the final model.
</Callout>
