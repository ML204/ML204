<Section label="What is it?">

**Optimization** means finding the input to a function that makes its output as small (or as large) as possible.

In machine learning, we always optimize the same kind of thing: we search for the model's parameters that make the errors as small as possible.

</Section>

<Section label="Why we need it">

Every machine learning model has numbers inside it called **parameters** — for example, the slope and intercept of a line, or the weights of a neural network.

Different parameter values give different predictions. Some predictions are close to the truth. Others are far off.

We need a way to find the parameter values that give the best predictions. That is what optimization does: it searches for the best parameters by minimizing a measure of error called the **loss**.

Without optimization, we would have to try every possible combination of parameter values by hand — which is impossible for real models with millions of parameters.

</Section>

<Divider />

<Section label="Explained in detail">

Imagine you are tuning a radio. You turn the dial and listen to the signal. When the signal is clear, you stop. You were minimizing the noise.

<Analogy>
  The dial is the parameter. The noise is the loss. Turning the dial until the signal is clearest is optimization.
</Analogy>

In math, we write a function $L(w)$ where:
- $w$ is the parameter (what we can change)
- $L$ is the loss (what we want to minimize)

The question is: **what value of $w$ makes $L(w)$ the smallest?**

That point is called the **minimum**. At the minimum, the function stops decreasing and starts increasing. The slope is exactly zero.

**Two kinds of minimum:**
- **Global minimum** — the absolute lowest point of the entire function.
- **Local minimum** — a point that is lower than its neighbors, but not the lowest overall. The function could be even lower somewhere else.

Simple functions like a parabola have one global minimum. Real ML loss functions are bumpy and have many local minima. Modern optimizers handle this surprisingly well in practice.

</Section>

<Section label="Notes & Formula">

The optimization problem in ML:

<Formula label="What we want to solve">
  $w^* = \arg\min_w \; L(w)$
</Formula>

<SymbolTable
  rows={[
    { symbol: 'w',          meaning: 'The parameter (or parameters) we are searching over' },
    { symbol: 'L(w)',       meaning: 'The loss function — measures how wrong the model is at parameter value w' },
    { symbol: 'w*',         meaning: 'The optimal parameter — the one that minimizes L' },
    { symbol: 'argmin',     meaning: 'Short for "the argument that minimizes" — returns the input, not the output' },
  ]}
/>

<Callout kind="info">
  $\arg\min$ returns the **input** that makes the function smallest. $\min$ returns the **output** (the smallest value itself). We want $\arg\min$ — we want the best parameters, not just the best loss score.
</Callout>

<Callout kind="warning">
  **Common mistake:** thinking optimization always finds the global minimum. In real ML, we usually find a good local minimum — and that is enough.
</Callout>

</Section>
