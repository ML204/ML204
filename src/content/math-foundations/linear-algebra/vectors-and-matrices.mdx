<Section label="What is it?">

A **vector** is an ordered list of numbers. Geometrically, it represents an arrow with a direction and a length (magnitude).

A **matrix** is a 2D rectangular grid of numbers organized into rows and columns. In machine learning, matrices bundle many data points together or represent linear transformations that stretch, rotate, or project data.

</Section>

<Section label="Why we need it">

Computers cannot look at a picture of a cat or read a patient's medical history directly. They only process numbers.

Linear algebra allows us to turn any real-world object into numbers:
- A house is represented as a feature vector: $[\text{bedrooms}, \text{square feet}, \text{age}]^T$.
- An entire dataset of $10\,000$ houses is organized into a matrix of shape $10\,000 \times 3$.
- An image is a matrix of pixel brightness values (or a 3D tensor with red, green, and blue channels).
- Neural network weights that transform input features into predictions are stored as matrices.

Linear algebra gives machine learning a unified mathematical language to manipulate millions of numbers simultaneously.

</Section>

<Section label="Explained in detail">

### 1. The Two Ways to Think About a Vector

There are two equally helpful ways to view a vector $\mathbf{v} = \begin{bmatrix} 3 \\ 2 \end{bmatrix}$:

1. **Computer scientist's view:** An ordered list of features. Here, $x_1 = 3$ and $x_2 = 2$.
2. **Physicist's view:** An arrow starting at the origin $(0, 0)$ and pointing to coordinate $(3, 2)$.

The length of this arrow is called its **magnitude** or **norm**, written $\|\mathbf{v}\|$. Using the Pythagorean theorem:

$$
\|\mathbf{v}\| = \sqrt{3^2 + 2^2} = \sqrt{13} \approx 3.61
$$

<Analogy>
  Think of a vector as driving directions: "drive 3 blocks East, then 2 blocks North". No matter where you start, that instruction is the same displacement.
</Analogy>

### 2. Vector Addition: The Parallelogram Rule

When you add two vectors $\mathbf{v}$ and $\mathbf{u}$, you add their matching components:

$$
\mathbf{v} + \mathbf{u} = \begin{bmatrix} v_1 \\ v_2 \end{bmatrix} + \begin{bmatrix} u_1 \\ u_2 \end{bmatrix} = \begin{bmatrix} v_1 + u_1 \\ v_2 + u_2 \end{bmatrix}
$$

Geometrically, this is "tip-to-tail" addition. Take vector $\mathbf{u}$, place its tail at the tip of $\mathbf{v}$, and the combined journey from origin to final destination is $\mathbf{v} + \mathbf{u}$. This forms a parallelogram.

### 3. Scalar Multiplication: Scaling and Flipping

A single regular number $c$ is called a **scalar**. Multiplying a vector by a scalar multiplies every single component:

$$
c \mathbf{v} = c \begin{bmatrix} v_1 \\ v_2 \end{bmatrix} = \begin{bmatrix} c v_1 \\ c v_2 \end{bmatrix}
$$

- If $c > 1$: the arrow stretches in the same direction.
- If $0 < c < 1$: the arrow shrinks.
- If $c < 0$: the arrow flips $180^\circ$ and points in the opposite direction.

### 4. From Vectors to Matrices

When we stack multiple column vectors side by side, we get a **matrix**:

$$
\mathbf{A} = \begin{bmatrix} \mathbf{u} & \mathbf{v} \end{bmatrix} = \begin{bmatrix} u_1 & v_1 \\ u_2 & v_2 \end{bmatrix}
$$

A matrix with $m$ rows and $n$ columns has dimension $m \times n$.
In ML:
- Row $i$ usually represents the $i$-th example (e.g. house #42).
- Column $j$ represents the $j$-th feature (e.g. square footage across all houses).

<Section label="Notes & Formula">

<Formula label="Vector Norm (Euclidean / L2 Length)">
  $\|\mathbf{v}\|_2 = \sqrt{\sum_{i=1}^{n} v_i^2} = \sqrt{v_1^2 + v_2^2 + \dots + v_n^2}$
</Formula>

<Formula label="Matrix Dimensions">
  $\mathbf{X} \in \mathbb{R}^{m \times n} \quad (m \text{ rows}, \; n \text{ columns})$
</Formula>

<Callout kind="tip">
  In machine learning conventions, standard vectors are almost always **column vectors** unless transposed ($[\cdot]^T$) into row vectors.
</Callout>

<Callout kind="warning">
  **Common mistake:** Adding vectors of different lengths. Vector addition is only defined when both vectors have the exact same number of dimensions.
</Callout>
